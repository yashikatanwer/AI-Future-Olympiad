# AIFO Implementation Plan

AIFO is designed to move from a school proposal into a real school program.

## School-facing journey
1. **Intro Meeting** — meet school administrators and customize dates, scope, and logistics.
2. **Deliver Sessions** — run the awareness session with real-life examples, live AI demos and interactive Q&A, followed by guided learning with a booklet, practice activities, simulations, and responsible-use lessons over the agreed learning period.
3. **Host Olympiad** — conduct the 60-minute assessment after students have had time to learn and practise, then award certificates according to the final school implementation plan.

## Delivery structure
- Phase 1: Awareness
- Phase 2: Learning Support
- Phase 3: Olympiad

The website is a digital support layer for these phases; it does not replace the school session or the real Olympiad.

## Important honesty rule
Only after real implementation should the project record actual school participation, students reached, sessions delivered, feedback, assessment results, certificates issued, or photos/media with permission.
